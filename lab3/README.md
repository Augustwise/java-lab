# Лабораторна робота №3

Консольний застосунок демонструє роботу з фігурами та побудований за шаблоном MVC.

## Структура MVC

- **Model:** `Shape`, `Rectangle`, `Triangle`, `Circle`, `ShapeModel` і компаратори.
- **View:** `ShapeView` виводить дані в консоль.
- **Controller:** `ShapeController` керує послідовністю обчислень, сортувань і виведення.
- **Main:** створює 12 заздалегідь підготовлених фігур і запускає контролер.

Програма:

1. виводить початковий масив фігур;
2. обчислює загальну площу всіх фігур;
3. обчислює загальну площу трикутників;
4. сортує фігури за зростанням площі через `Comparator`;
5. сортує фігури за кольором через інший `Comparator`.

## Запуск

Потрібні JDK 17 і Maven.

```shell
mvn test
mvn compile exec:java
```
